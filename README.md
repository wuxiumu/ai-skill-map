# AI 技能图谱 · ai-skill-map

> 计划做成可视化的 **AI 技能/工具学习路径图**（节点、前置、资源链接），方便个人成长与团队培训对齐。  
> **现状：上游空仓**——本仓先钉死定位与 MVP 路线图，不假装成品。

**定制：** 微信 **qingbao199101**（备注：技能图谱）｜ [wuxiumu@163.com](mailto:wuxiumu@163.com)

## 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| AI 技能树 / 学习路径可视化方案 | 已上线的完整课程平台 |
| 可嵌入文档站/内网培训的图谱组件规划 | 自动爬取全网课程的聚合站 |
| 按岗位/赛道定制图谱的起点 | LMS 成绩与证书中台 |

## MVP 路线图

1. **M1**：图谱数据模型（JSON/YAML）+ 静态 SVG/Canvas 渲染 demo  
2. **M2**：节点详情侧栏（资源链接、难度、前置）+ 搜索过滤  
3. **M3**：编辑器最小版（增删改节点、导出）  
4. **M4**：嵌入 SDK + 白标 + 团队只读分享链接  

详见 `docs/ROADMAP.md`。
